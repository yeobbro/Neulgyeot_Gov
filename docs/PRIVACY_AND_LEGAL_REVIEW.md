# 개인정보·법률 검토 메모

> **법률 자문이 아닙니다.** 개발 설계 근거를 정리한 내부 메모이며, 실제 운영 전 지자체 개인정보보호책임자·법무 검토와 최신 법령(국가법령정보센터) 확인이 필요합니다. 검토 기준일: 2026-11-03.

## 관련 법령과 설계 반영
| 법령 | 요지(개략) | 설계 반영 |
|---|---|---|
| 개인정보 보호법 제15조 | 수집·이용 요건(동의, 법률상 근거 등) | 수집 항목 최소화, 카테고리별 목적·근거 기록 |
| 제17조 | 제3자 제공 요건 | 병원→지자체 제공은 동의 scope·법적 근거 메타데이터 없이 수신하지 않음 |
| 제18조 | 목적 외 이용·제공 제한 | 수신 목적(`purpose`) 저장, 다른 용도(예: 외부 AI) 기본 차단 |
| 제19조 | 제공받은 자의 이용·제공 제한 | 지자체는 받은 정보를 제공기관에 최소 정보만 노출(가명·권역·주기) |
| 제23조 | 민감정보(건강 등) 처리 제한, 별도 동의/법령 근거 | 건강 관련 항목은 별도 동의 없으면 거부, 근거 미기재 시 `pending_review` |
| 제29조 | 안전성 확보조치 | 접근통제(RBAC/ABAC/RLS), 접속기록(감사 로그), 암호화 전송(HTTPS) — 저장 암호화·접속기록 점검 절차는 운영 단계 과제 |
| 의료법 제21조 | 환자 기록 열람·사본 제공 제한(예외 규정) | 진료기록 원문·전체 투약·간호기록 미수신, 주진단·투약 요약은 기본 정책 차단 |
| 의료·요양 등 지역 돌봄의 통합지원에 관한 법률(2026.3.27 시행) 및 시행령·시행규칙 | 지자체 통합지원 신청·조사·지원계획·연계 체계 | 업무 흐름·상태 설계에 반영. 정보 제공·조회 근거 조항은 **기관 법무 확인 필요** |
| 지자체 조례·기관 지침 | 지역별 상이 | 서비스 카탈로그·승인 권한·모니터링 주기·수신 항목을 설정값으로 분리 |

## 원칙
- "동의 = 전부 허용"이 아님: 카테고리별 목적·수신기관·항목·보유기간·법적 근거·별도동의 필요 여부를 `consent_evidence`에 저장하고 판정.
- 직접식별자 분리 보관, 열람 시 감사.
- 통계 화면·CSV에 개인 식별 정보 미노출. 지도에 개인 위치 미표시.
- DEMO 환경에 실제 개인정보 입력 금지(화면 배너).

## 남은 검토 과제
1. 통합지원법상 정보 요청·제공 근거 조항과 동의 없이 처리 가능한 범위 확정
2. 개인정보 영향평가(공공기관) 필요 여부
3. 외부 클라우드(Vercel, Managed PG) 이용 시 위탁·국외이전 검토, 공공 클라우드 보안인증(CSAP) 요구 여부
4. 외부 LLM 사용 시 위탁계약·비식별 기준
5. 보유기간·파기 절차의 공공기록물 관리 규정 정합성
