# 로드맵 (미구현 항목 — 구현 완료 아님)

## 운영 전 필수
- Managed PostgreSQL 연결, 백업/PITR, 마이그레이션 파이프라인
- 운영 계정 생성·권역 배정 UI, 외부 IdP/기관 SSO 어댑터
- 실제 병원·기관 연계(협약 규격, 인증, 재시도·dead-letter, 웹훅 서명)
- 공유 rate limit(Firewall/Redis), nonce 기반 CSP, 세션 폐기 목록·비밀 이중 키 회전
- 보존기간 만료 파기 배치, idempotency 레코드 정리
- 개인정보 영향평가·법무 검토 결과 반영, 저장 데이터 암호화 범위 결정

## 기능 로드맵 우선순위

### P0 — 실제 기관 파일럿 전 필수
- [x] 실제 행정동 명칭·참고 중심 좌표와 실제 도로 지도 배경 적용(강남구 DEMO 기준)
- [ ] 행정안전부/국가데이터처 행정구역 코드 마스터 정기 동기화 및 코드 변경 이력
- [ ] Managed PostgreSQL, 백업/PITR, 운영 환경 변수·세션 비밀 설정
- [ ] 실제 지자체 조직·권역·사용자 생성 및 담당 권역 배정 UI
- [ ] 제공기관 디렉터리: 실명, 사업자/기관 식별정보, 주소·좌표, 제공 서비스, 관할 구역, 수용 현황, 출처·최종 확인일을 관리하는 관리자 CRUD
- [ ] 권한별 지역 접근, 주소/위치 비식별화, 지도 소집단 통계 억제 기준 검증

### P1 — 담당자 업무 효율
- [ ] 사례관리 업무 캘린더: 가정방문, 통합지원회의, 서비스 시작·종료, 정기 모니터링 일정
- [ ] 담당자별 사례 수·예정 업무량·기한 초과 현황과 재배정 제안(자동 재배정은 관리자 승인)
- [ ] 알림센터: 배정, 보완 요청, 기관 수락/수행 불가, 일정 변경, 기한 도래·초과
- [ ] 서비스 제공기관 편집·수용 현황 확인 요청 및 만료/미확인 상태 표시
- [ ] 보고서 스냅샷 목록·비교·내보내기 승인과 다운로드 이력 조회

### P2 — 기관 간 연계·지역 분석
- [ ] 병원·보건소·장기요양·복지기관 시스템별 표준 API/파일 연계, 서명 웹훅, 재시도·실패 큐
- [ ] 실제 행정경계 폴리곤 및 생활권 레이어(공식 데이터 출처·라이선스 검토 후)
- [ ] 자원 커버리지·대기시간·미충족 수요 대시보드(출처, 기준일, 누락률, 표본 수 공개)
- [ ] AI 회의록·지원계획 초안 후속업무 변환(문장별 출처, 사람 검토·승인 필수)

### 별도 제품
- 가족(제품 C)·대상자 포털은 별도 앱·인증·데이터 경계로 개발한다.
