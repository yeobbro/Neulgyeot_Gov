# 로드맵 (미구현 항목 — 구현 완료 아님)

## 운영 전 필수
- Managed PostgreSQL 연결, 백업/PITR, 마이그레이션 파이프라인
- 운영 계정 생성·권역 배정 UI, 외부 IdP/기관 SSO 어댑터
- 실제 병원·기관 연계(협약 규격, 인증, 재시도·dead-letter, 웹훅 서명)
- 공유 rate limit(Firewall/Redis), nonce 기반 CSP, 세션 폐기 목록·비밀 이중 키 회전
- 보존기간 만료 파기 배치, idempotency 레코드 정리
- 개인정보 영향평가·법무 검토 결과 반영, 저장 데이터 암호화 범위 결정

## 기능
- 서비스 카탈로그·기관 편집 UI, 업무 상태 라벨 지자체별 커스터마이징
- 실제 행정경계 지도(라이선스 확인 후), 보고서 스냅샷 조회 화면
- 알림 UI(현재 DB 기록만), 일정 캘린더
- 가족(제품 C)·대상자 포털은 별도 제품
