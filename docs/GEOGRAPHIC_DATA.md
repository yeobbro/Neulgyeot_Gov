# 지리 데이터 출처와 표시 범위

## 시연 범위

현재 지자체용 DEMO는 **서울특별시 강남구**를 실제 지리 참조 지역으로 사용한다. 서울시 공개 현황 기준 강남구에는 행정동 22개와 법정동 14개가 있으며, 행정동은 주민센터 운영 등 행정 편의를 위한 단위이고 법정동은 법률상 주소에 사용하는 단위다.

이번 DEMO에는 기존 합성 사례와 권역 담당 범위를 보존하기 위해 아래 4개 행정동만 매핑했다.

| 기존 내부 ID | 실제 행정동 | 참고 중심 좌표 (위도, 경도) |
|---|---|---|
| `rg_haesol` | 역삼1동 | 37.50084, 127.03550 |
| `rg_daon` | 대치4동 | 37.50157, 127.05480 |
| `rg_maru` | 수서동 | 37.48692, 127.10010 |
| `rg_saebom` | 세곡동 | 37.47066, 127.10430 |

자치구 중심은 강남구 전체 보기의 지도 기준점으로만 사용한다. 세부 좌표는 지도 레이블과 시연 화면을 위한 근사 참고점이며 법적·공식 주소 좌표로 사용하면 안 된다.

## 출처

- [서울특별시 자치구별 동 현황](https://www.seoul.go.kr/seoul/autonomy_sub.do) — 강남구 행정동·법정동 명칭과 두 단위의 정의.
- [국가데이터처 행정동 정보(2025-07-04)](https://www.data.go.kr/data/15136373/fileData.do) — 행정동 코드·계층 구조의 공식 마스터 데이터 후보. 운영 반영 시 최신 파일과 코드 변경 이력을 다시 검증해야 한다.
- [서울시 행정동 경위도 좌표 공개 참고자료](https://kimhongsi.tistory.com/entry/%EA%B3%B5%EA%B0%84-%EC%9E%90%EB%A3%8C-%EC%84%9C%EC%9A%B8%EC%8B%9C-%ED%96%89%EC%A0%95%EB%8F%99-%EA%B2%BD%EC%9C%84%EB%8F%84-%EC%A2%8C%ED%91%9C) — 행정동 중심점 좌표를 참고해 DEMO용 근사점을 설정했다. 공식 원천 마스터로 대체해야 한다.
- [OpenStreetMap](https://www.openstreetmap.org/) — 지도 배경 및 도로·지명 렌더링. 지도 하단에 저작자 표시를 유지한다.

## 실제 데이터와 합성 데이터의 경계

**실제 지리 참조:** 강남구·행정동 이름, 공개 지도 배경, 권역 대표 중심점.

**합성 시연 데이터:** 지자체 테넌트, 공무원 계정, 서비스 제공기관, 연락처, 기관 주소, 수용 현황, 병원 연계, 대상자, 사례, 조사, 지원계획, 회의, 서비스 의뢰, 업무 이력.

- DEMO 제공기관은 실제 기관을 뜻하지 않으며 실제 주소·좌표가 없다.
- 지도에는 제공기관·대상자·가구 위치 핀을 표시하지 않는다.
- 권역 핀은 근사 중심점이다. 공식 행정동 경계 폴리곤이 아니다.
- 내부 DB 코드 `GN-...`는 이 DEMO에서 사용하는 내부 식별자이며 행정안전부 공식 행정동 코드가 아니다.
- 지역 목록의 4개 동은 시연 범위이며 강남구 전체 22개 행정동을 모두 등록한 상태가 아니다.

## 운영 제품으로 전환하기 전

1. 행정안전부 행정동 코드와 국가데이터처 행정동 정보의 기준일·계층을 확인하고 코드 변경 이력을 관리한다.
2. 공식 행정경계 폴리곤과 공간 기준 좌표를 허가된 공개 데이터에서 적재하고 원천·갱신일·라이선스를 보관한다.
3. 실제 서비스 제공기관은 기관별 확인·검증 절차를 거쳐 주소, 좌표, 제공 서비스, 관할 권역, 연락처, 수용 현황, 확인일을 별도 관리한다.
4. 개인의 주소·방문 위치는 권한과 목적을 엄격히 제한하며 기본 지도·광역 통계에는 노출하지 않는다.
5. OpenStreetMap 표준 타일 서버는 최선 노력(best-effort)이며 가용성 SLA가 없다. 현재 시연용 임베드에만 사용하고 상용/기관 운영 전에는 계약된 지도 서비스나 VWorld 등으로 전환 여부를 검토한다. [OSM 타일 사용 정책](https://operations.osmfoundation.org/policies/tiles/)을 준수한다.
