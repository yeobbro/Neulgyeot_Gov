# 데모 가이드

`/login`에서 DEMO 계정을 선택합니다(개발 또는 `DEMO_MODE=true` 환경만). 모든 데이터는 합성(가온시·누리군)이며, 인메모리 DB는 서버 재시작 시 초기화됩니다.

| 계정 | 역할 | 범위 |
|---|---|---|
| 김지원 (DEMO 관리자) | 시·군·구 관리자 | 가온시 전체, 공식 판정 확정 권한(ABAC) |
| 이하늘 (DEMO 담당자) | 사례관리 담당자 | 해솔동·다온동 |
| 박도윤 (DEMO 담당자) | 사례관리 담당자 | 마루동·새봄동 |
| 최서연 (DEMO 방문간호) / 정민호 (DEMO 식사지원) | 서비스 제공기관 | 자기 기관 의뢰 |
| 한감사 (DEMO 감사) | 감사 담당자 | 감사 로그 |
| 퇴직자 (DEMO 비활성) | — | 로그인 차단 확인용 |
| 누리군 관리자 (DEMO) | 다른 테넌트 | 격리 확인용 |

## 추천 시연 순서
1. 관리자: 통합 현황 → '병원 퇴원 연계 접수' → REF-…-0001 → 담당 지역·담당자 배정
2. 담당자(이하늘): 연계 상세 → 사례 생성 → 조사·평가 11개 영역 작성 → 검토 요청 → 평가 확정
3. 지원계획 작성 → 검토 요청 → 통합지원회의 등록 → 결과 기록(승인 권고)
4. 관리자: 계획 승인(근거 입력)
5. 담당자: 서비스 연계 탭 → 후보 확인(이유·주의·제외 사유) → 의뢰
6. 제공기관(정민호): 의뢰 수신함 → 수락 → 일정 등록 → 시작 → 결과 제출
7. 담당자: 모니터링 기록(계획 변경 필요) → 사례 종결
8. 감사: 감사 로그에서 조회·거부·내보내기 이력 확인
9. 권한 확인: 이하늘로 `/cases/case_5`(마루동) 접근 → 찾을 수 없음

## 병원 연계 API 시연 (curl)
```bash
curl -X POST "$APP_URL/api/integrations/hospital/referrals" \
  -H "Authorization: Bearer demo-hospital-integration-key-not-a-secret" \
  -H "Idempotency-Key: demo-$(date +%s)" -H "Content-Type: application/json" \
  -d @tests/fixtures/referral.json
```
(데모 키는 공개 값입니다. 운영 배포에는 `HOSPITAL_INTEGRATION_DEMO_KEY`를 변경하거나 연계 클라이언트를 비활성화하세요.)
