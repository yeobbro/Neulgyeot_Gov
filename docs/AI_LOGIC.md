# AI 행정 업무 보조

AI는 행정 판단을 대체하지 않습니다. 3개 기능만 제공합니다.

| 기능 | 대상 | 섹션 |
|---|---|---|
| 연계 신청 요약 | 병원 연계 | 확인된 주요 사실 / 돌봄 욕구·요청 서비스 / 누락·불일치·추가 확인 |
| 사회복지 종합 소견서 초안 | 사례 | 대상자 주요 현황 / 기능·일상생활 지원 필요 / 주거·돌봄 환경 / 희망 서비스 / 추가 확인 사항 / 검토 가능한 지역 서비스 후보 |
| 회의 자료·사례 요약 | 사례 | 타임라인 요약 / 서비스 연계 공백 / 미완료 후속 업무 / 회의 질문 |

## 동작
1. 서버가 **사실(Fact) 목록**을 만든다: 각 사실은 `F번호`, 텍스트, 출처(`sourceType:sourceId·field`). 입력은 승인된(accepted) 연계 항목, 조사에서 '확인됨' 항목, 계획·의뢰·업무 등. `pending_review`/정책 차단 항목은 포함하지 않는다.
2. **기본 엔진 = 규칙 기반**: 사실이 있을 때만 해당 문장을 생성(외부 전송 없음).
3. 선택적 LLM: `AI_FEATURE_ENABLED=true` + `ANTHROPIC_API_KEY` + 관리자 설정 `ai_enabled` 모두 충족 시에만. 이름·코드 없는 사실 문장만 전송, JSON 스키마 강제. 실패·검증 실패 시 규칙 엔진 결과 사용.
4. **검증(`lib/domain/ai-draft.ts`)**: 모든 문장은 존재하는 F번호를 1개 이상 인용해야 하며, 자격·수급 판정, 긴급성·위험도, 진단·예후, 낙인 표현 패턴은 거부.
5. `ai_drafts(status='draft')` + `ai_source_references` 저장. 담당자가 수정·승인해야 확정(사례는 '검토 승인' 기록으로 저장). 폐기 가능. 생성·승인·폐기는 감사 이벤트.

## 제한
- 길이를 맞추지 않으며, 근거 없는 섹션은 "근거 자료 없음 — 확인 필요"로 표시.
- 실제 개인정보의 외부 AI 처리에는 별도 개인정보 영향평가·위탁 계약 검토가 필요(미수행).
- rate limit: 사용자당 20회/분.
