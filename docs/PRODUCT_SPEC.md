# 제품 명세 — 늘곁 지자체용 MVP v0.1

## 목적
지역사회 통합돌봄 업무(신청 → 조사·종합판정 → 개인별 지원계획 → 서비스 제공·연계 → 모니터링)를 담당자가 일관되게 처리·기록하도록 돕는다. 공식 행정 시스템·법정 판정을 대체하지 않는다.

## 사용자
| 역할 | 범위 |
|---|---|
| 시·군·구 관리자 | 지자체 전체, 배정, 계획 승인(정책 설정), 설정, 감사 로그, 보고서 |
| 사례관리 담당자 | 담당 권역 열람, 배정된 사례만 수정 |
| 서비스 제공기관 | 자기 기관 앞 의뢰만, 최소 정보 |
| 감사 담당자 | 감사 로그·상태 이력·내보내기 이력, 사례 본문 접근 불가 |

## 업무 규칙 요약
- 조사: 11개 영역 × 5개 응답 상태. 미기재·무응답은 정상으로 처리되지 않으며 확정 전 모두 명시 필요. 자체조사와 공식 통합판정 구분(공식 판정은 ABAC 권한자만 확정).
- 계획: DRAFT에서 바로 승인 불가. 회의 상정 시 회의 결과(승인 권고)가 기록되어야 승인 가능. 승인은 근거 입력 필수, 승인 권한은 `tenant_settings.plan_approval_roles`.
- 서비스 의뢰: 승인된 계획 항목만, 항목당 진행 의뢰 1건, 수행 불가 사유 필수, 기관/담당자 단계 분리.
- 모니터링: 미수행·부분 수행 사유 필수, 계획 변경 필요 시 계획 CHANGE_REVIEW·사례 PLAN_REVIEW, 주기는 지자체 설정.
- 종결: 진행 중 서비스가 있으면 불가, 사유 필수.
